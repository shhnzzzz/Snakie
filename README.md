# 🐍 Snakie

A classic Snake Game built with **HTML, CSS, and JavaScript**.

🎮 **Play Now:** https://shhnzzzz.github.io/Snakie/

---

## 🎯 Objective

Control the snake, eat the food to grow longer, and survive as long as possible without hitting the walls or your own body.

---

## 🎮 How to Play

1. Open the game using the link above.
2. Click the **Start Game** button.
3. Use the **Arrow Keys** to control the snake:

   * ⬆️ Up
   * ⬇️ Down
   * ⬅️ Left
   * ➡️ Right
4. Eat the red food to increase your score.
5. Avoid colliding with the walls or your own body.
6. Try to beat your **High Score**, which is saved in your browser.

---

## ✨ Features

* 🐍 Classic Snake gameplay
* 🍎 Random food generation
* 📈 Live score tracking
* 🏆 High score saved locally
* ⏱️ Game timer
* 💀 Game Over screen
* 🔄 Restart button
